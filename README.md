# 📒 Address Book System

A simple **Address Book System built using C++** that allows users to manage contact information through a command-line interface.

This project was developed to practice and demonstrate fundamental C++ programming concepts such as **classes, objects, functions, vectors, file handling, searching, sorting, and basic Object-Oriented Programming (OOP)**.

## 📌 Project Overview

The Address Book System provides a convenient way to store and manage contact details.

Users can perform basic operations such as:

* ➕ Add a new contact
* 👀 View all contacts
* 🔍 Search for a contact
* ✏️ Update contact information
* 🗑️ Delete a contact
* 📋 Manage multiple contacts
* 💾 Store contact information using files
* 🔤 Sort contacts
* 🚪 Exit the application

The project is completely **terminal/console based**, making it simple to run and understand.

## ✨ Features

### 1. Add Contact

Allows the user to enter and save a new contact with details such as:

* Name
* Phone Number
* Email
* Address
* Other contact information

### 2. View Contacts

Displays the contacts currently stored in the address book.

### 3. Search Contact

Allows users to search for a contact using available contact information.

### 4. Update Contact

Existing contact details can be modified when required.

### 5. Delete Contact

Users can remove a contact from the address book.

### 6. Sorting

Contacts can be organized according to selected information, making them easier to find and manage.

### 7. File Handling

Contact information can be stored and retrieved using files so that the data can be maintained between program executions.

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/shahukarirohith-wq/Address-Book-System-c-project-.git
```

### Step 2: Open the Project

Open the project folder in an IDE such as:

* Visual Studio Code
* Code::Blocks
* Dev-C++
* Visual Studio

### Step 3: Compile the Program

If you are using `g++`:

```bash
g++ main.cpp -o address_book
```

### Step 4: Run the Program

On Windows:

```bash
address_book
```

On Linux/macOS:

```bash
./address_book
```
